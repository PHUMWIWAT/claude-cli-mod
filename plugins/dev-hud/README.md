# dev-hud

A Claude Code mod for developers: after every turn it shows, in the status line under the prompt, the model in use, its effort level (low, medium, high, xhigh, max), how long the last turn took, how many model requests the session has sent, what the session has cost so far, and how long the session has been running.

## Install

```
/plugin install dev-hud --marketplace PHUMWIWAT/claude-cli-mod
```
