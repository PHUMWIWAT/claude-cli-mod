# token-weather

A Claude Code mod that shows a live weather forecast of your context window in the status line under the prompt, updated after every turn: ☀ Clear under 25%, ☁ Cloudy to 49%, ☂ Showers to 74%, ☇ Storm to 89%, and ↯ Compact soon from 90%. It also shows the percentage used, tokens used out of the window, a sparkline of the last 12 turns, and how much the last turn added.

## Install

```
/plugin install token-weather --marketplace PHUMWIWAT/claude-cli-mod
```
